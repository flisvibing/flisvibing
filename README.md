## What I'm building

### [Lesspecad](https://github.com/flisvibing/lesspecad )

A privacy-first Android browser with a built-in offline ad blocker,
incognito browsing, tab groups, extensions, reader mode, and cloudless
backup features.

Built with Kotlin, Jetpack Compose, Room, Coroutines, and WebView.

### [Chesst](https://github.com/flisvibing/chesst ) (will rename it Chessyl soon)

A full-stack chess analysis platform powered by Stockfish.

It includes game analysis, a personal game archive, an ECO opening
explorer, JWT authentication, and Lichess and Chess.com integrations.

Built with Java, Spring Boot, PostgreSQL, Stockfish, and vanilla JavaScript.
